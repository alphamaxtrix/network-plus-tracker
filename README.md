Network+ Study Tracker

A self-contained, single-file study tracker for Professor Messer's free CompTIA N10-009 Network+ video course. Check off videos as you watch them and track your progress toward the exam.

Live site: https://alphamaxtrix.github.io/network-plus-tracker/

Features
All 87 videos from the course, organized by section and subsection
Click a video to mark it complete — progress saves automatically in your browser
Per-section progress bars in the sidebar
Overall completion percentage and time watched / time remaining
Direct links to each video on Professor Messer's site
No build step, no dependencies — a single HTML file
Usage

Just open index.html in a browser, or visit the live site above. Click any video row to toggle it complete. Progress is stored locally in your browser (localStorage), so it's tied to whichever browser/device you use — it won't sync across devices.

To reset your progress, use the "Reset progress" button in the bottom right.

Tech

Plain HTML, CSS, and vanilla JavaScript. No frameworks, no build tools. Hosted for free on GitHub Pages.
